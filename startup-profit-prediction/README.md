# 📈 Startup Profit Prediction
Predicting the profit of startups based on R&D Spend, Administration, Marketing Spend, and State using **Multiple Linear Regression**.

## 📊 Dataset
The dataset contains the following columns:
- **R&D Spend** 💡: Amount spent on research and development.
- **Administration** 🏢: Administrative expenses.
- **Marketing Spend** 📢: Amount spent on marketing.
- **State** 📍: Location of the startup.
- **Profit** 💰: Target variable (what we want to predict).

## 🛠️ Technologies Used
- Python 🐍
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## 🔍 Steps in the Project
1. **Data Exploration**: Understanding dataset and relationships.
2. **Data Preprocessing**: Handling categorical variables with One-Hot Encoding.
3. **Model Training**: Multiple Linear Regression.
4. **Evaluation**: MAE, MSE, and R² score.
5. **Visualization**: Heatmap of correlations, predictions vs actual values.

## 📌 Results
- **Mean Absolute Error (MAE)**: 7514.293659643097
- **Mean Squared Error (MSE)**: 83502864.03255911
- **R² Score**: 0.9347068473282567
