🛒 E-Commerce Sales Prediction — Linear Regression from Scratch
📌 Overview
This project predicts E-Commerce sales revenue based on advertising spend across different marketing channels.
The unique part of this project is that Linear Regression was implemented from scratch without using machine learning libraries like scikit-learn — to understand the math and logic behind the algorithm.

📊 Dataset
The dataset contains:

TV Advertising Spend 💵

Radio Advertising Spend 📻

Newspaper Advertising Spend 📰

Sales Revenue 📈

🛠️ Steps
Data Exploration — load and inspect the dataset.

Visualization — understand correlations between variables.

Implementation — code Linear Regression manually using Gradient Descent.

Evaluation — compute metrics like Mean Squared Error (MSE) and Mean Absolute Error (MAE).

📈 Results
The model successfully predicts sales with good accuracy.

Learned how gradient descent updates weights step-by-step.

Clear understanding of the math behind regression
